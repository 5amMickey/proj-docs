### The studio

Michael Brandt started Phantom Break in 2018 as the name for his game projects, mentoring and talks in the Calgary game community. His first plan, an RPG called Alpha World, was too large for a team of two, and he shelved it. He incorporated Phantom Break Inc. in Calgary, Alberta on [2022-12-13]. Phantom Break makes story-driven games in Unreal Engine with a small core team and contractors. Michael writes the stories and builds the studio's procedural art tools in Houdini. Each project has left tools the next one uses. Project Dawn built the character pipeline. Project Silence built the movement system and the facial animation tests. ### Project Runner and ProjectSilence

Project Runner is a side-on cyberpunk narrative game in five episodes, built in Unreal Engine 5.8. Development started on 2026-10-01. ProjectSilence is a later stealth action game with its own story, world and lead. They are separate games that share code.

The shared parts are two in-house Unreal plugins and one tool library:

- PhantomInteraction: interactable objects, hold-to-hack devices, camera zones and crouch zones.
- PhantomStory: the bridge between the StoryFlow dialogue system and Unreal's Sequencer cinematics, timed choices, and checkpoint saves.
- The studio library of Houdini tools and materials used to build environments.

Both plugins are built for Project Runner first. ProjectSilence picks them up later, which is why the hold-to-hack device and the crouch zones are written as general components.

How the two are coordinated:

1. Project Runner is the only project in active development during the prototyping period. [Confirm. If ProjectSilence or anything else has active work, say who, how many hours, and when.]
2. The plugins live in one version-controlled repository. Each game pins its own copy and its own version of StoryFlow, so a change for one game can't break the other.
3. Only Project Runner work is charged to the Project Runner budget. Plugin work done during the prototype is Runner work, because Runner needs it. Nothing is charged to two projects. Timesheets name the project, and the project has its own accounts.
4. ProjectSilence has no open CMF file. Its conceptualization closed in 2025.
