# Character animation pipeline research (2026-10-28)

Scope: UE 5.8, side-on narrative game, walk-only player, background NPC crowds, Sequencer cinematics. Facts carry a URL. "Unconfirmed" marks what I could not verify in a primary source. Several fetches (Epic Animation Mixer doc, Sequencer Animation track doc, Adobe Mixamo help page, SideFX export docs) returned empty or blocked pages, so those gaps are listed at the end.

## 1. Mixamo

**Official bulk option.** None found. The Mixamo FAQ I could reach does not mention one (https://community.adobe.com/t5/mixamo-discussions/mixamo-faq-licensing-royalties-ownership-eula-and-tos/td-p/13234775). Adobe's own help FAQ returned 403 (https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html), so the official page is unread.

**Community tools.**
- gnuton/mixamo_anims_downloader: `downloadAll.js` runs in the browser console on mixamo.com and pulls every animation for one chosen character via the Mixamo API. A second script uploads .obj/.fbx characters and downloads chosen animations. No documented skin, fps or in-place options; no licence file named; last commit date not shown (https://github.com/gnuton/mixamo_anims_downloader).
- UE forum script "Mixamo download script": downloads all animations, has a flag for regular, in-place or root variants, supports mirrored but not sliders. It reuses your last-used page settings, so download one sample by hand first. Site changes broke an earlier version (https://forums.unrealengine.com/t/script-mixamo-download-script/101815).
- paulpierre/MixamoHarvester: exports all animations as FBX, resumes interrupted runs, needs a Mixamo Bearer token (mirror: https://github.fleetingtimer.workers.dev/paulpierre/MixamoHarvester). Original repo not opened.
- FPS and "without skin" for these scripts: unconfirmed. Read the script source before relying on them.

**Status 2025-2026.** A third-party guide says Mixamo still works as of September 2026, free with an Adobe ID, no shutdown announced, no meaningful updates since 2015, and a multi-day outage in June 2025 (https://app.cinevva.com/guides/free-character-animations-rigging). That is a single secondary source. Treat Mixamo as a risk: download everything you need now and keep it.

**Licence.** The 2022 FAQ lists video games and DLC as allowed, with no fees or attribution. The only bans are redistributing raw character or animation files as the product, and using the content to train ML models. It calls Mixamo a "limited duration technology preview" (https://community.adobe.com/t5/mixamo-discussions/mixamo-faq-licensing-royalties-ownership-eula-and-tos/td-p/13234775). It does not address uploaded characters. A forum answer says you can upload a custom character (https://community.adobe.com/t5/mixamo-discussions/characters-and-animation-for-commercial-use/td-p/14782095). Unconfirmed: commercial terms for uploaded characters. Check Adobe's current Terms of Use.

**Skeleton naming and UE retarget.** Bones are named `mixamorig:Hips` etc. (Auto-Rig Pro's Remap doc uses that example: https://www.lucky3d.fr/auto-rig-pro/doc/remap_doc.html). Epic's Auto Retargeting page: right-click assets, "Retarget Animation Assets", set Target Preview Mesh, pick animations, Export Animations. With Auto Generate Retargeter on (default) it builds the IK Rig and IK Retargeter, and chain matching uses fuzzy bone names ("exact name matches are not required"). It lists UE4/UE5 Mannequin, MetaHuman and Stack O Bot as examples and does not mention Mixamo (https://dev.epicgames.com/documentation/unreal-engine/auto-retargeting-in-unreal-engine). So Mixamo working via auto-retarget is unconfirmed; test it. Fallbacks: the MIT-licensed arbitrarygames/mixamo2unreal (UE 5.2+; only a Mixamo to MetaHuman retargeter exists, Manny is planned, not shipped) (https://github.com/arbitrarygames/mixamo2unreal), or the paid UNAmedia plugin (https://unamedia.com/ue5-mixamo/docs/tutorial/).

## 2. Other Mannequin-compatible libraries

- Game Animation Sample (GASP): motion-matching locomotion and traversal project on Fab (https://dev.epicgames.com/documentation/unreal-engine/game-animation-sample-project-in-unreal-engine). Its Fab listing says 500+ animations work with the UE5 Mannequin through runtime retargeting (https://fab.com/s/46a85e1ef0c5). Its docs set up a UEFN_Mannequin source retargeter registered in `ABP_GenericRetarget` as `RTG_UEFN_to_{asset}`. Licence terms: unconfirmed.
- Fab free packs: a 24-animation pack for Manny/Quinn listed as free for commercial use (https://www.fab.com/listings/8de31c5d-93bc-4bd4-9606-ca789ce91b99). MoCap Central sample pack, 120+ animations on the Mannequin, licence unconfirmed (https://www.fab.com/listings/fba58a40-dc18-475a-b726-b04345f39697).
- ActorCore: free mocap moves as FBX at 24/30/60 fps with Unreal presets, per a third-party blog (https://3dart.it/download-free-mocap-moves-rigged-characters). Terms unconfirmed; check Reallusion.
- Rokoko and Move AI free libraries: not found.

## 3. Retargeting cost

**Runtime retarget.** Epic documents it as a way to "retarget to other characters without generating new Animation Sequences, or during Live Link sessions", using Retarget Pose From Mesh with Use Attached Parent. If the source mesh is hidden, set Visibility Based Anim Tick Option to Always Tick Pose and Refresh Bones (https://dev.epicgames.com/documentation/unreal-engine/runtime-ik-retargeting-in-unreal-engine). The page gives no per-frame CPU figure and no crowd guidance. Epic's IK Retargeter page says each retarget operation has custom LOD thresholds and Profile Ops shows per-op runtime (https://dev.epicgames.com/documentation/unreal-engine/ik-rig-animation-retargeting-in-unreal-engine). No Epic statement on many NPCs found. Third-party UNAmedia says IK retargeting is best for offline asset generation and "can be expensive for runtime" (https://docs.unamedia.com/ue5-mixamo/ue5-runtime-retargeting). Profile it yourself.

**Offline.** Export retargeted sequences via Retarget Animation Assets (link in section 1). The result is ordinary animation on the target skeleton, so no retarget cost at runtime. That is inference, not a quote.

**Leader Pose vs Copy Pose.** Forum reports only: Copy Pose costs about the same as another mesh component; Leader Pose can override AnimBP logic, curves and control rig; Copy Pose with update-rate optimisation can lag a frame (https://forums.unrealengine.com/t/leader-pose-component-overrides-animation-blueprint-logic/2642584, https://forums.unrealengine.com/t/copy-pose-from-mesh-vs-master-pose/371579). Epic's copy-pose page: https://dev.epicgames.com/documentation/unreal-engine/copy-a-pose-in-unreal-engine. Animation Sharing plugin docs: not found.

**Houdini KineFX.** Retargeting uses Rig Match Pose (conforms rest poses), Map Points (pairs joints), Full Body IK (per-frame transfer), and Joint Deform for preview (https://www.sidefx.com/docs/houdini/character/kinefx/retargeting.html, https://www.sidefx.com/docs/houdini/nodes/sop/kinefx--rigmatchpose.html). The retargeting page does not cover baking. Export: ROP FBX Animation Output saves animation from an animated skeleton; ROP FBX Character Output saves mesh, skeleton and optionally animation (forum summary, https://www.sidefx.com/forum/topic/76626, https://www.sidefx.com/forum/topic/102718/). A baked FBX is plain joint animation, so zero runtime cost; that follows from FBX being baked keys, and I found no SideFX page stating it. Set the FBX version to FBX201800 for Unreal (https://www.sidefx.com/docs/houdini/unreal/fbx.html). Houdini 21 note: for APEX rigs the mesh needs a prim name attribute or export fails (https://www.sidefx.com/forum/topic/102718/).

## 4. Auto-Rig Pro

Export options (https://www.lucky3d.fr/auto-rig-pro/doc/ge_export_doc.html): Humanoid type gives Mannequin axes, naming and IK bones in one preset. Mannequin Axes needs 4 spine + 1 neck bones for UE4, or 6 spine + 2 neck for UE5. Also: Rig Name `root`, Rename for UE, Add IK Bones, Units x100. Root motion needs the armature object animated (it is the FBX root node); the Root Motion option bakes `c_traj` onto it. Known issues on that page: UE 5.5/5.6 mishandle glTF morph targets and animations (works in 5.7); skeleton-only export needs a dummy mesh; spine/shoulder differences from Manny need reference bone reshaping or Skeleton translation retargeting; finger rotations may need offsets baked. Older versions had bind-pose problems, fixed in 3.78.49. Joint orientation: Mannequin Axes is the stated fix; the doc lists no specific mismatches.

Remap (https://www.lucky3d.fr/auto-rig-pro/doc/remap_doc.html): has a Mixamo preset, but built-in presets target Auto-Rig Pro armatures. Steps: Build Bones List, check mapping, Replace Namespace if needed, match rest poses, Re-Target, Interactive Tweaks (Euler only).

Price: Lite $25, Full (adds Smart, Remap, FBX/GLTF export) $50, 12 months of updates, Blender 2.93 to 5.2 (https://superhivemarket.com/products/auto-rig-pro). Licence: source GPL v3 but not freely redistributable; generated rigs are yours; AI binaries one device per licence (https://www.lucky3d.fr/auto-rig-pro/doc/license.html). You need Full for Remap and export.

## 5. Layering

- Layered Blend Per Bone: blends poses across a bone set, Branch Filter or Blend Mask modes (https://dev.epicgames.com/documentation/unreal-engine/animation-blueprint-blend-nodes-in-unreal-engine).
- Slots and montages: a Slot node feeding a Layered Blend Per Bone so only the upper body is affected (Epic's "Upper Body Slot" example). Slots are mainly for montages "but also work in Sequencer". Slot groups: a montage in the same group stops the running one (https://dev.epicgames.com/documentation/unreal-engine/animation-slots-in-unreal-engine).
- Linked Anim Layers: swap graph sections at runtime via layer interfaces; Epic's example drives upper body from a weapon AnimBP over lower body from the main graph (https://dev.epicgames.com/documentation/unreal-engine/using-animation-blueprint-linking-in-unreal-engine).
- Sequencer to AnimBP slot: a forum answer says add the AnimBP (not the character Blueprint) to Sequencer, set each animation track's slot name, and blend with track weight. One user on UE 4.16 saw only one animation play (https://forums.unrealengine.com/t/is-it-possible-to-use-multiple-animation-slots-in-sequencer-to-layer-animations/427244). Epic's Animation track page returned no content, so verify in 5.8.
- Animation Mixer: Epic's forum tutorial calls it "the experimental Anim Mixer plugin for Unreal Engine 5.8", mixing and layering sources in Sequencer with looping, blending and root motion, tied to UAF and Animation Blueprints (https://forums.unrealengine.com/t/tutorial-animation-mixer-in-sequencer-intro/2731468). A third-party article says a mixer track holds a base animation plus additive/override layers with animatable weight, and layers can be masked to upper body, an arm or the head, but its walkthrough is "conceptual" and it expects UI changes across hotfixes (https://www.strayspark.studio/blog/animation-mixer-ue5-8-sequencer-tutorial). The 5.8.1 hotfix fixed several Anim Mixer crashes (https://forums.unrealengine.com/t/5-8-1-hotfix-released/2738864). A community tutorial shows it in UE 5.6 (https://forums.unrealengine.com/t/community-tutorial-ue-5-6-seamless-gameplay-to-cinematics-2-animation-test-with-sequencer-anim-mixer-subtitled/2548655), so the first version is unconfirmed. Whether it targets AnimBP montage slots: unconfirmed. Epic's own Animation Mixer doc page returned no content.

## 6. Root motion

Epic: Root Motion from Everything extracts motion from every root-motion-enabled asset in the final pose, weighted; Montages Only takes it just from montages. Either option moves the Anim Graph update to the Game Thread, which "can cause performance issues". Walking/Falling ignores Z root motion. Root Motion Root Lock (Ref Pose, Anim First Frame, Zero) exists (https://dev.epicgames.com/documentation/unreal-engine/root-motion-in-unreal-engine). The page has no CMC or locomotion recommendation. In-place loops plus CMC for a walk-only player is my inference, not an Epic statement, with Montages Only for any scripted moves.

Mixamo: root motion sits on Hips, and UE needs a ground-anchored root bone (forum reports: https://forums.unrealengine.com/t/problem-with-mixamo-animations-after-adding-root-bone-in-blender/1172455, https://forums.unrealengine.com/t/rotational-issues-root-motion-mixamo/2002588). Tools: enziop mixamo_converter Blender add-on (users disagree on whether it works past Blender 2.8; link not verified), paid AnimExport Pro (https://superhivemarket.com/products/animexport-pro), or a manual root bone in Blender moving Hips location keys to the root. Watch for a -90 degree Z rotation on import.
